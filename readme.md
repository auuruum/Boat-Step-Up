# Boat Step Up Mod for Minecraft 1.21.1–1.21.11

Boat Step Up lets boats step up one-block height changes. The project provides
Fabric, Quilt, Forge, and NeoForge builds.

The Fabric metadata declares compatibility with Minecraft 1.21.1 through
1.21.11. The release is compiled against Minecraft 1.21.11.

Build with:

```text
.\gradlew.bat build
```

Fabric and NeoForge target Java 21. ForgeGradle 7 also requires a Java 25
toolchain for its Mavenizer.
